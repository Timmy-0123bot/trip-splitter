# 旅の割り勘（trip-splitter）

友達との旅行で使う、立替精算（割り勘）のWebアプリです。
誰が何を立て替えたかを記録しておくと、最後に「誰が誰にいくら払えばよいか」を自動で計算します。

**公開URL：https://timmy-0123bot.github.io/trip-splitter/**

ログインもインストールも不要で、スマホのブラウザで開くだけで使えます。

## 解決する課題

- 旅行中に、誰が何を立て替えたのか分からなくなる
- 最後の精算で「誰が誰にいくら払えばいいか」の計算に時間がかかる
- 海外旅行では円と外貨の支払いが混ざり、さらに分かりにくくなる

## できること

- **支払いの記録**：払った人・金額・通貨（円または外貨1種類）・内容・割る人を記録し、一覧で確認・削除できます
- **円に換算して合計**：外貨のレートを自分で入力すると、すべての支払いを円にそろえて、合計と1人ごとの負担額を表示します
- **精算結果の表示**：「AさんがBさんに3,200円払う」の形で、できるだけ少ない受け渡し回数になるよう表示します（1円単位）

## 使い方

1. **メンバーを追加する**：旅行に参加する人の名前を入力して「追加」を押します
2. **外貨のレートを入力する**（海外旅行のとき）：通貨コード（例：USD）と「1USD＝何円」を入力します
3. **支払いを記録する**：払った人、金額、通貨、内容（例：タクシー）を入力します。割る人は初期状態で全員にチェックが入っているので、割らない人だけチェックを外して「記録する」を押します
4. **精算結果を見る**：画面下の「精算結果」に、誰が誰にいくら払えばよいかが表示されます

### 計算のルール

- 外貨の支払いは、入力したレートで1円単位に四捨五入して円に換算します。レートを変えると、これまでの外貨の支払いもすべて計算し直されます
- 割り切れない端数は、払った人が負担します（例：10,000円を3人で割ると、払った人が3,334円、ほかの2人が3,333円）

### データの保存について

- 入力したデータは、使っている端末のブラウザ（ローカルストレージ）に保存されます。ページを閉じても消えません
- データはほかの人の端末とは共有されません。旅行中は代表の1人が、1台のスマホで記録するのがおすすめです
- 別のブラウザで開いたり、ブラウザのデータを消したりすると、記録は見られなくなります

## 開発者向け

React + Vite で作っています。`main` ブランチにプッシュすると、GitHub Actions で自動的に GitHub Pages に公開されます。

```bash
npm install      # 依存パッケージのインストール
npm run dev      # 開発サーバーの起動（http://localhost:5173/trip-splitter/）
npm run build    # 本番用ビルド
```
